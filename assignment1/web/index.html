规则与操作

黑棋先行。在横、竖或斜线方向连成至少 K 子即获胜；棋盘落满且无人获胜为和棋。本作业采用自由连珠规则，无禁手。

点击交叉点落子。键盘可用 ↑↓←→ 移动光标，用 Enter 或 空格 落子。开启「手数」可查看每一步编号。

人机模式悔棋会回到上一轮人的回合。AI 对战可暂停、逐步观察；思考中的一步完成后再暂停。界面支持 N = 5–30，K = 3–N。

思考时长影响搜索强度。搜索统计来自实际对局；不同机器可能完成不同深度。棋谱 JSON 可用于复盘记录。
