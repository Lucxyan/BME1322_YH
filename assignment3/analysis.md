# 简答

1. 在这次数据预算下，稀疏访问的 $(s,a)$ 对先学模型再规划这条路线具有更明显的**误差传播风险**。模型法必须同时估计该动作的转移概率和平均奖励；少量样本形成的偶然概率会在价值迭代中被反复使用，还可能影响其他状态的价值。Q-Learning 在稀疏动作上也会得到不稳定的 Q 值，尤其这里的主实验使用固定学习率 0.3，但它不会显式拟合整行转移概率。本实验的 B1 每个动作仅被访问 20–29 次；单个数据集不能证明模型法的实际策略波动一定更大。

2. 主实验使用学习率 0.3 时，两条路线在 B2–B9 的策略全部一致，因此主结果没有不一致状态。为分析差异，在同一数据上增加接口默认学习率 0.5 的 Q-Learning 对照：模型法在 B3 选择 `w`，该对照选择 `g`。模型法中 B3 的 `w` 与 `g` 的规划动作值分别约为 4.590 和 3.445，而对照 Q 表中两者约为 4.351 和 4.724。一种可能原因是**价值传播路径不同**：模型法对经验后继分布求期望并反复规划，而固定学习率 0.5 的 Q-Learning 按样本顺序更新，后期样本可能改变 B3 的动作排序。这个不一致案例来自附加参数对照，不能当作学习率 0.3 的主实验结果。
