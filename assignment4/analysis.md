# 讨论题

## 1. 线性核与 RBF 核

采用 decision_function 连续分数和固定五折等权平均 AUC，线性核最优为 0.9112，RBF 核最优为 0.9086，因此本实验按 AUC 选择线性核。
RBF 的 Accuracy 为 0.8481，高于线性核的 0.8448，说明模型偏好依赖预先选择的指标。
RBF 调参后仍未超过线性核的 AUC，支持这组编码下线性决策面已捕捉较多有效信号的解释。
保持 C=1，把 gamma 从 0.01 提高到 10，训练 AUC 从 0.9229 升至 1.0000，验证 AUC 从 0.9086 降至 0.7120。
由 exp(−gamma·‖x−x′‖²) 可知，大 gamma 使相似度随距离快速衰减，模型更依赖训练点附近的局部结构，训练与验证差距扩大。
固定参数从线性核换为 RBF 的 AUC 变化为 -0.0130，而 RBF 调参带来 +0.0111 的变化，因此本次调参比直接换核带来更大的正向收益。
逐折差值表见 report.md，该选择结论限于本次固定五折和扫描范围。

## 2. 分类与回归结论

线性 SVM 的最优 AUC 为 0.9112，高于 RBF 的 0.9086，因此按本次固定五折平均 AUC 选择线性核。
回归中，岭回归 R² 为 0.5258，高于限制深度树的 0.2921 与后剪枝树的 0.2673。
分类按平均 AUC 选择线性核，回归按平均 R² 选择岭回归，两条线都支持本实验中全局线性模型的适用性。
二次岭回归最高 R² 为 0.4210，低于一阶岭回归的 0.5258，进一步支持当前样本量与编码下全局加性趋势较容易稳定估计的解释。
两个线性模型按绝对系数排序的前五特征有 4 项重合，为 ca, cp, oldpeak, thal，为两条任务依赖主要信号的一致性提供旁证。
分类关注 num=0 的边界，回归还拟合正例内部的等级差异，AUC 与 R² 也不能跨任务直接比较高低。
这些结果仍可能受样本量、类别编码和特征相关性影响，无法据此认定真实关系处处线性。
去除 ca 与 thal 后还需按初筛时实际可用的特征评估，不能仅凭全特征排名推断临床表现。

## 3. 把岭回归用于分类

| 模型/阈值 | AUC | Accuracy | F1+ |
| --- | --- | --- | --- |
| 岭回归 ≥ 0.3 | 0.9116 | 0.7228 | 0.7605 |
| 岭回归 ≥ 0.5 | 0.9116 | 0.7624 | 0.7808 |
| 岭回归 ≥ 0.7 | 0.9116 | 0.8183 | 0.8157 |
| 岭回归 ≥ 1.0 | 0.9116 | 0.8513 | 0.8283 |
| SVM linear | 0.9112 | 0.8448 | 0.8219 |
| SVM rbf | 0.9086 | 0.8481 | 0.8248 |

岭回归的排序 AUC 直接用预测值计算，因此阈值只改变 Accuracy 和 F1。


岭回归连续预测的 AUC 为 0.9116，与线性 SVM 的 0.9112 很接近。
四个阈值中，1.0 的 F1+ 最高，为 0.8283，线性 SVM 的 F1+ 是 0.8219。
阈值为 0.3 时，岭回归的 F1+ 降为 0.7605，此时按 F1+ 反而落后于 SVM。
因此“是否逊于分类器”会随评价指标和决策阈值而变，AUC 与某个阈值下的 F1+ 可以给出不同答案。
由于 E[num｜X]=P(num>0｜X)×E[num｜num>0,X]，回归目标同时包含阳性概率与阳性病例严重程度的信息，拟合 num 因而可能给出有用的分类排序。
不同阳性概率与严重程度可以产生相同的分级期望，所以该预测值不能直接解释成阳性概率，分级损失也不会专门优化二分类边界。
阈值是用这组折外预测做的探索，实际部署阈值需要在独立数据上再验证。
